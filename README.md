# নূরানী মাসনূন দু'আ ও কালিমাহ্ (স্লাইড প্রেজেন্টেশন)
**মারকাযুল ঈমান - দাওয়াহ্ বিভাগ**

আল্লামা কারী বেলায়েত হুসাইন (রহ.)-এর মূল কিতাব **"নূরানী পদ্ধতিতে কুরআন শিক্ষা"** অনুযায়ী সংকলিত পূর্ণাঙ্গ মাসনূন দু'আ ও ৬টি কালিমার ডিজিটাল স্লাইড প্রেজেন্টেশন ওয়েব অ্যাপ্লিকেশন।

---

## 🧭 বৈশিষ্ট্যসমূহ

1. **ট্রেজার ম্যাপ (Treasure Map) ভিন্টেজ পার্চমেন্ট ডিজাইন:**
   - প্রাচীন মানচিত্র ও ভিন্টেজ পার্চমেন্ট পাণ্ডুলিপির মতো দৃষ্টিনন্দন আবহ।
   - অ্যান্টিক ব্রাস বর্ডার, কর্নার কারুকাজ (⚜) এবং সোনালী মেডেলিয়ন।
   - ঐতিহ্যবাহী লাল মোমের সিলমোহর (Royal Wax Seal) ব্যাজ।
2. **কোনো দু'আ সংখ্যার উল্লেখ নেই:**
   - নির্দেশনামতে টাইটেল বা হেডারে দু'আর নির্দিষ্ট সংখ্যা (যেমন ৬০ বা ৬১) সম্পূর্ণ পরিহার করা হয়েছে।
3. **কিতাবের ৬টি মৌলিক কালিমাহ্ (শেষে সংযুক্ত):**
   - পৃষ্ঠা ৪৫–৪৭ এর মূল কিতাব অনুযায়ী ৬টি কালিমাহ্ হুবহু সন্নিবেশিত।
   - টপ বার ও ক্যাটাগরি মেন্যুতে আলাদা ডেডিকেটেড গোল্ডেন বাটন (`📜 কালিমাহ্`)।
4. **১০০% নির্ভুল বিশুদ্ধ হাদীস রেফারেন্স:**
   - কিতাবের নিজস্ব প্রমাণের পাশাপাশি সহীহ বুখারী, সহীহ মুসলিম, সুনানে আবু দাউদ, জামে তিরমিযী ও ইবনে মাজাহ্-এর সুনির্দিষ্ট নম্বরযুক্ত সনদ।
5. **১-ক্লিক PPTX এক্সপোর্ট:**
   - ব্রাউজার থেকেই সম্পূর্ণ প্রেজেন্টেশনটি পাওয়ারপয়েন্ট (PPTX) ফাইলে ডাউনলোড করা যায়।
6. **আরবী ফন্ট ও সাইজ কন্ট্রোল:**
   - Scheherazade New, Amiri, Noto Naskh Arabic, Lateef, Harmattan ফন্ট নির্বাচন ও সাইজ বৃদ্ধি/হ্রাসের সুবিধা।
7. **ট্রেজার সূচিপত্র ও লাইভ সার্চ:**
   - যে কোনো দু'আ বা কালিমার শিরোনাম, বাংলা উচ্চারণ, অর্থ বা আরবী শব্দ লিখে সাথে সাথে খুঁজে বের করা যায়।
8. **মোবাইল ও টাচ সোয়াইপ ফ্রেন্ডলি:**
   - টাচ স্ক্রিন সোয়াইপ এবং কীবোর্ড অ্যারো দিয়ে স্বাচ্ছন্দ্যে স্লাইড নিয়ন্ত্রণ।

---

## 📂 ফাইলসমূহ

- `index.html` - মূল ট্রেজার ম্যাপ স্লাইড প্রেজেন্টেশন ওয়েব অ্যাপ।
- `slides_printable.html` - প্রিন্ট ও PDF বুকলেটের জন্য মার্জিত সংস্করণ।
- `data.js` - ৬৮টি আইটেম সমৃদ্ধ সম্পূর্ণ ডাটাবেস।
- `build_data.js` - ডাটাবেস জেনারেটর স্ক্রিপ্ট।
- `generate_html.js` - এইচটিএমএল বিল্ডার স্ক্রিপ্ট।
- `generate_printable.js` - প্রিন্ট ভার্সন বিল্ডার স্ক্রিপ্ট।

## 🚀 কীভাবে চালাবেন?

ব্রাউজারে সরাসরি `index.html` ফাইলটি ডাবল ক্লিক করে ওপেন করলেই চলবে। কোনো সার্ভার ইনস্টলেশনের প্রয়োজন নেই।
পুনরায় বিল্ড করতে চাইলে:
```bash
npm run build
```
